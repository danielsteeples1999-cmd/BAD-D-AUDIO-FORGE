# BAD-D // AUDIO FORGE — CURRENT CONTROL PLANE

Mission: a standalone specialist audio/DJ experimentation lab for real music, transitions, timing, continuity, perceptual testing, and Auto-DJ boundary validation.

Loop: QUESTION -> LOCATE -> FIXTURE -> BASELINE -> EXPERIMENT -> MEASURE -> ATTACK -> REGRESS -> RECORD -> ADVANCE

Hard boundaries:
- Never modify private BAD-D production.
- No production secrets, credentials, or private data.
- No automatic production promotion.
- Never weaken evidence or fail-closed gates.
- Production integration only through an explicit adapter/contract.
- Human listening is separate evidence from numerical measurement.

First milestone: AUDIO-AUTODJ-001. Prove a real audio fixture can pass through an actual measurable local audio path, be attacked, compared for regression, and produce machine-readable evidence.

Default cycle budget: 20 minutes, 8 experiments, 5 repeats, 12 sweep values, 16 concurrent jobs, 500 MB generated data, 50 MB persisted results.

Evidence:
PROVEN = directly measured.
INFERRED = supported but not directly demonstrated.
UNKNOWN = not tested.
BLOCKED = required capability unavailable.

Priority:
1. Real audio execution + evidence
2. Audio attack/recovery
3. Transition/timing
4. Perceptual regression
5. Resource/long-run stability
6. Explicit BAD-D adapter contract
7. Higher-level music intelligence

Final report: BUILT / TESTED / EVIDENCE / ATTACKED / REGRESSION / LIMITATIONS / REUSABLE CAPABILITY / QUEUE CHANGE / NEXT ACTION / ONE HUMAN TEST
